① 定位

② 对运营的理解

③ 对岗位的理解

三、商业模型：拼多多到底靠什么赚钱

一句话：拼多多本质是一个「流量交易所」——用低价把买家聚过来，再把这波注意力竞价卖给商家，赚广告费。和 Google 靠竞价广告变现的逻辑同构。

三方杠杆图（平台 / 商家 / 买家）
主体付出得到他的算盘
平台补贴、营销资源、流量位广告费（核心）+ 技术服务费 + 资金沉淀算 ROI：把有限资源给最能转化的单品
商家广告费 + 让出单件毛利（降价）订单规模 → 摊薄成本 → 薄利多销压供应链成本，才撑得住低价
买家注意力 + 复购极致性价比多快好省

而运营，就是站在平台这一侧，调这三方的杠杆。

飞轮：它为什么能越转越快

买家多 → 流量池大 → 商家更愿意投广告 → 商家多、竞价激烈 → 价格更低、供给更全 → 买家更多 → 复购

这是个正循环。运营的价值就是让这个飞轮转得更快——不是发券，不是上下架，是在飞轮上做调优。

最深一层：养商家 > 压商家

商家的利润空间越大，平台的广告收入才越可持续。

  • 短期看，运营像在「压商家」（要低价、要投放）
  • 长期看，运营是在「养商家」（让他赚钱，他才持续投）

拼多多 2024 年推「百亿减免」、2025 年推「千亿扶持」，主动减商家负担，就是这个道理——生态健康是长期变现的前提。

利润 → 运营板块的对应
运营板块核心职责利润驱动
商家运营 / 商务 BD扩容商家生态拉高广告竞价底座
品类运营打造品类爆款撬动交易服务费（GMV）
活动 / 流量运营流量极致配给提升全盘 CVR 与流量价值
商业化 / 策略运营优化变现工具直接拉升广告收入

一句话：帮商家把 GMV 做上去 → 商家赚到钱 → 他愿意投更多广告 → 平台赚广告费。「帮商家赚钱」和「让商家多投广告」其实是同一件事。

四、思维模型（分析任何问题都用它）

口诀：AARRR 定「在哪一段」，人货场定「哪一方」，事前事中事后定「什么时候」。
三个维度各问各的，不是三层嵌套（嵌套会变成 45 个格子，没用）。

一级：三个主体，各自的骨架
主体它的骨架它的工具箱
人
（买家）		AARRR 漏斗：拉新 → 激活 → 留存 → 变现 → 推荐需求洞察（调研/访谈/评论分析）、分层（RFM、新老客、价格敏感度）
货
（商品+商家）		选品 → 价格带 → 成本 → 库存 → 供给品类结构、SKU 规划、动销/周转/滞销
场
（平台/场景）		流量 → 坑位 → 机制 → 规则推荐位、百亿补贴/秒杀、赛马算法、服务分、SLA

AARRR 不是凌驾一切的主线，它是「人」这条线的骨架——用户的旅程本来就是拉新到推荐。

三组关系（每组都是双向的）
关系方向一方向二本质
人货人有没有这个需求货的价格/品质能不能满足供需匹配
人场平台能不能把人引来人在场里愿不愿意停留触达与体验
货场场给货多少资源货给场多少产出效率与配给

「双向」的实战价值：CVR 掉了，立刻要问——是用户不想要了（需求侧），还是货不行/贵了/主图差了（供给侧）？问对方向，才不会乱改。

二级：三个阶段，是三种问法（定 / 调 / 算）

阶段不是换项目，是换视角。同一件事，三个阶段三种问法：

对象事前（定）事中（调）事后（算）
库存备多少消得多快、会不会断剩多少、周转几天、滞销多少
价格定多少要不要临时调实际成交价、毛利多少
流量规划多少分给哪个货值不值（ROI）
人打哪些人群进没进来、买没买还买不买（复购）

锚点是「流量爆发 / 交易发生」那一刻。开售前做准备，爆发时做调优，结束后做复盘。

三级：异常归因——先分内外
类型包含
外部
（调目标）		宏观（消费环境、季节）、供应链（涨价、产能、物流）、竞争对手（降价、上新、抢流量）、平台侧（算法调整、规则变化）
内部
（改动作）		预测偏差、选品失误、定价没竞争力、执行不到位、库存断货或积压、跨部门协同

规则：外部异动 → 调整预期和节奏；内部问题 → 改动作和流程。这一刀切下去，归因永远不会乱。

五、五步排查法（拿 CVR 下降当例子）

第 1 步 · 看指标，定位关系
大促 CVR 掉 → 这是人货的问题（人进来了，但不买）。

第 2 步 · 分两侧，看是需求还是供给
需求侧（人）：人群打偏了吗？大促拉来的是薅羊毛的，还是目标用户？
供给侧（货）：价格有竞争力吗？主图行不行？SKU 全不全？库存够不够？评价拉不拉？

第 3 步 · 顺漏斗，找卡在哪一跳
曝光 → CTR → 进店 → 加购 → CVR → 复购
加购高但下单低 = 卡在最后一跳；加购也低 = 前面没打动；CTR 也低 = 压根没吸引力。

第 4 步 · 往前推，归因到阶段
如果是断货、缺 SKU → 是事前的预测和备货问题；如果是价格没竞争力 → 是事前的定价问题。

第 5 步 · 别跨阶段乱推因果
CVR 低不等于复购低或客诉高，前后不必然相关。每个阶段的指标单独看。

背诵版：「先定位指标到关系，再分需求侧供给侧，再顺漏斗找卡点，再往前归因到阶段，最后别跨阶段推因果。」

七、场景地图：招、扶、谈、冲、盯、清

① 招（招商）

干什么：找供给。看哪个品类的哪个价格带缺货，去对应的产业带把工厂招进来。

你对口：你能判断一个工厂「能不能做到这个价、能不能供得上量」。

② 扶（培育）

干什么：新商家不会玩，你教他——改标题关键词、换主图、调价格带、报活动、开推广。

你对口：做过 SOP、做过批量化处理——「教别人按标准做」你干过。

③ 谈（谈价格和资源）—— 行业小二最核心的活

干什么：商家说「这个价我做不了」。你帮他算账：成本多少、平台流量折算成多少钱、规模起来后成本能降多少。谈成了，他降价，你给流量扶持和活动位。

这是你最硬的一张牌：你能算清商家的账，不是凭感觉压价。

④ 冲（大促）

干什么：组织货盘（爆款 + 引流款 + 利润款）、报名单、分流量、实时盯数据、处理异常。

你对口：大促和产能高峰是同一件事——提前备、峰值调、事后复盘。

⑤ 盯（数据监控）

干什么：每天看品类大盘——谁在涨、谁在掉、哪个价格带缺供给、哪个商家的转化突然崩了。

你对口：预测偏差体系、看板、双阈值巡检，就是「盯」的能力。

⑥ 清（商家治理）

干什么：违规、假货、延迟发货、服务分低的，警告 → 限流 → 清退。

你对口：判断「是标准不合理还是人没执行」的能力是一样的。

九、平台理解

赛马机制：拼多多流量分配的底层逻辑

同质化的商品放一起比：价格更低、点击率更高、转化率更高、服务分更高的，算法给更多流量。

所以运营的核心动作是：帮商家把价格打下去、把主图做好、把转化提上来、把服务分守住 → 换流量。

拼多多 vs 淘宝 vs 抖音
  • 淘宝：重「店铺资产」（粉丝、复购、店铺权重），人找货、搜索驱动。
  • 拼多多：弱化店铺、以单品为核心，货找人、推荐流驱动 → 所以新店能一夜爆，淘宝不行。
  • 抖音：内容驱动，用内容激发需求。
用户洞察（你的真实观察，别人没有）

商品卡三要素：封面吸引注意 → 价格降低决策门槛 → 「已拼 10 万+」提供信任背书，再加先用后付降低支付摩擦。

本质：它把交易决策链上的摩擦一个个拆掉了，所以转化效率特别高。

时效战：2024 年「电商西进」免偏远地区二段运费，2025 年「免费送货入村」，2026 年 8 月首页上线「最快明天达」。

一句话收：京东拿备货换时效，拼多多拿补贴换时效——都是拿钱换体验，只是一个投在仓里，一个投在补贴上。

GMV 两种拆法（别用错）

商家运营岗先报这个：GMV = 商家数 × 单个商家的产出

  • 商家数上去 = 招商
  • 单商家产出上去 = 培育
  • 低效商家清掉 = 淘汰治理

再补一句：「单商家产出可以进一步拆成 UV × 转化率 × 客单价」——两个层次都说到，面试官会知道你分得清平台视角和用户视角。

十一、二面题卡（业务主管 · 场景题为主）

你负责的品类 GMV 突然下降 20%，怎么排查？

直接上五步排查法：① 定位到指标和关系；② 分需求侧/供给侧；③ 顺漏斗找卡点；④ 往前归因到阶段；⑤ 别跨阶段推因果。

你怎么给用户分层？用到下沉市场第一步调什么

RFM（最近消费/频次/金额）+ 新老客区分。下沉市场第一步：更侧重价格敏感度——提高优惠券/首购礼金权重，把目标从「情怀召回」换成「性价比留存」。

对接的商家态度不好、不信任平台，你怎么沟通？

先听他的痛点（是不是利润薄、流量拿不到）→ 再摆平台能给的价值（流量扶持、活动资源位）→ 用一个小范围的低价测试或数据案例建立共识。

核心：不是压他，是帮他算清楚这笔生意值不值得做。

让你策划一场大促活动，你怎么做？

定目标（拉新/冲 GMV）→ 选人群 → 定货盘（爆款 + 引流款 + 利润款）→ 定机制（拼团/百亿补贴/券）→ 定节奏（预热-爆发-返场）→ 数据监控与复盘。讲闭环，比讲创意更有说服力。

拼多多和淘宝、京东、抖音的运营差异是什么？

一句话：淘宝是店铺资产 + 人找货，拼多多是单品 + 货找人 + 赛马分配流量，抖音是内容激发需求。

了解轮岗机制吗？可以接受吗？

接受。并补一句：「而且我四个方向都有过接触，所以不管定到哪个都不是从零开始。」

实习时遇到过最紧急的任务？怎么扛下来的？

用美的的素材：多任务并行时按重要紧急排序 + 用工具自动化把重复劳动干掉（加单工具 2 小时 → 20 分钟）。先止血，再根治。

十二、三面题卡（HRBP · 查户口 + 稳定性）

籍贯、Base、长期定居、父母职业、是否独生子女、家人是否支持去上海

【如实】+ 统一口径：家里支持，我愿意在上海长期发展、认真考虑定居。

秋招进度怎么样？手里有其他 offer 吗？更倾向哪个？

说「投得不多、很聚焦，主要是平台型和供应链/运营方向」。说实话、不隐瞒，但把落点放在「我更想确认拼多多这个方向」。

期望薪资 / 对薪资结构有什么想法

别先报数。

反问薪资结构和定级，说「符合市场水平即可，我更看重成长空间」。要报就给事先查过的区间。

3 年小目标：你希望成为什么样的运营人

前 1 年把基本功打扎实，跑通一个品类/行业的完整链路；第 2-3 年能独立负责一个行业方向，成为懂商家、懂数据、懂货的运营。具体、谦逊，别画大饼。

能否接受 11-11-6？怎么看互联网的高强度？

干脆接受 + 结合经历：「我理解这个行业的节奏，也经历过项目冲刺期。我更能从结果和快速成长里获得成就感。」不要在 HR 面改口，要和前面一致。

十四、避坑与提醒

  • 别用「这不复杂」的语气。换成「我擅长把复杂的事做简单」。
  • 商业模型别讲成课。点到为止，最后落回动作：「所以我做商家运营的目标就是帮商家把 GMV 做起来，他自然会投更多广告。」
  • 三面后可能「泡池子」1-3 个月。别为了等拼多多放弃别的机会。
  • 一天三轮，考的是体力和状态。早点睡，吃好饭。
  • 先结论后细节，每题 2-3 分钟，别啰嗦。
  • 客服轮岗 / 高压 / 轮岗这类意愿题，表态要干脆，犹豫就扣分。
  • 简历上每个数字都要能说清口径：700+、100% ROI、2304 行、2 小时→20 分钟。

附：京东物流运营 · 二面速查

三个动作（处理到岗时间）

① 给锚点：我在美的的实习签到 12 月底。
② 问需求：用人部门希望的到岗时间大概是什么时候？
③ 给方案：能等 → 12 月底交接完到岗；要提前 → 我可以协调，但需要留交接时间。

别说「我尽可能不毁约」（听起来像可能放鸽子），要说「我会把交接做好，有始有终」。

为什么选京东（三层）

① 我看懂了你们在做什么——仓配一体的一体化供应链，本质是拿备货换确定性。

② 这里是能把我用到极致的地方——岗位明确要做 AI 辅助运营改善，我真的用它解决过问题（加单 2h → 20min）。

③ 我认同这家公司的做事方式——当年所有人不看好自建物流，它坚持投了十几年。这种长期主义我认同。

场景题：时效/准时率掉了怎么查

拆链路找掉点：揽收 → 分拨 → 干线 → 末端，按环节拆时长和达成率，定位掉在哪一段再对症。

接一句：我在美的是用同样思路做产能巡检——设阈值、超了自动报警、先定位环节再定位原因。

场景题：爆仓 / 库存不准怎么处理

爆仓：提前预测单量 → 备人备场地备设备 → 峰值动态调配 → 异常预案（跨仓调拨、临时场地）→ 事后复盘。

库存不准：先找源头是哪个环节漏扫错扫（收货/上架/拣货/退货）→ 规范扫码 + 系统校验兜底 → 异常预警。

带一句你的判断：难的不是系统，是数据的实时性和准确性——任何环节扫错，下游全歪。

能接受下一线吗 / 能接受 11-11-6 吗

干脆接受：「不了解现场做不好运营，这是必经的。」
